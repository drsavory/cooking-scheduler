# 0016 – Plan screen: compact dish rows

**Status:** accepted

The Plan screen exists to add dishes and set when each one is prepped, cooked and rested.
Dish cards had grown to two columns with stacked, labelled boxes, so only two or three dishes
fitted on a screen next to the Kitchen load panel.

Each dish is now two lines:

1. Name, then its times as chips (prep / in / out / serve), the appliance badge, and the
   view / more / remove actions on the right.
2. The inputs in one row, with the label inside each box: **Prep, Cook, Rest** first, then a
   divider and the heat and space settings (temp, scale, space and oven for oven dishes; ring
   size for hob dishes; appliance for the rest).

Issues (clashes, over capacity) go on a third line only when there are any. Notes, recipe link
and the prepped / ingredients checkboxes stay behind the "more" button. Autosave is unchanged.
On narrow screens the rows wrap, two boxes to a line.
